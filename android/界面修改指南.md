# 界面怎么预览、怎么修改

当前版本已将 Java + XML 前端接入你现有的 NleCloudApi。运行时显示真实云端读数，历史从本次运行开始积累；设备在线状态尚未由现有接口提供。

## 在 Android Studio 中看 XML 画面

1. 打开工程目录 仓库内的 `android/`。
2. 执行 **File → Sync Project with Gradle Files**，等待同步结束；再运行一次 `app`，确保 Material 控件及自定义 View 已编译。
3. 打开 `app/src/main/res/layout/activity_main.xml`，点击编辑器右上角 **Split** 或 **Design**。这个文件现在通过 `<include>` 引用真实首页，底部导航也在这里，不再是等待 Java 动态填入的空容器。
4. 如需修改单页，分别打开 `page_dashboard.xml`、`page_history.xml`、`page_devices.xml`。页面已指定 `Theme.IOT3` 主题和 `.MainActivity` 预览上下文，常用控件的宽高也明确写在布局里。
5. 预览仍停留在旧画面时，点击预览区域刷新。主题选择 `Theme.IOT3` / `IOT3`；深色效果可以切换预览的 Night 模式，或运行后在设备页切换主题。

若同步后仍空白，点击预览右上角红色感叹号查看具体异常。本机已有日志曾记录 `MaterialButton ClassNotFoundException` 和字体 `assetStream is null`，这是编辑器渲染异常，不能仅凭 APK 能运行就判定预览正常。不要直接删除缓存、升级依赖或改 SDK 来碰运气。

本次已修复页面引用、预览上下文、图表示例数据和 XML 可读性；由于电脑窗口捕获超时，尚未直接确认你当前 Android Studio 的预览窗格恢复。实际 APK 已重新构建并在模拟器检查。

## 想改什么，打开哪个文件

以下路径都相对于工程目录：

| 想修改的内容 | 文件 | 修改位置 |
| --- | --- | --- |
| 首页卡片顺序、尺寸、留白 | `app/src/main/res/layout/page_dashboard.xml` | 搜索 `temperature_value`、`humidity_value`、`light_value`，找到各卡片 |
| 历史页布局 | `app/src/main/res/layout/page_history.xml` | 筛选 ChipGroup、趋势图、统计卡片 |
| 设备页布局 | `app/src/main/res/layout/page_devices.xml` | 设备信息、设置按钮和开关 |
| 底部导航的高度、图标颜色 | `app/src/main/res/layout/activity_main.xml` | `bottom_navigation` |
| 导航标题和图标 | `app/src/main/res/menu/bottom_nav.xml` | 三个 item |
| 标题、按钮、说明文字 | `app/src/main/res/values/strings.xml` | 按 string 的 name 搜索 |
| 浅色配色 | `app/src/main/res/values/colors.xml` | `background`、`hero`、`accent`、`text_primary` 等 |
| 深色配色 | `app/src/main/res/values-night/colors.xml` | 对应同名颜色 |
| 卡片圆角、文字字号 | `app/src/main/res/values/themes.xml` | `Panel`、`Heading`、`Metric`、`Body` 等样式 |
| 手机与平板左右留白 | `app/src/main/res/values/dimens.xml` 和 `values-sw600dp/dimens.xml` | `page_padding` |
| 后端字段与数值映射 | `app/src/main/java/com/example/iot3/network/NleSensorMapper.java` | `Temperature`、`Humidity`、`Light` 和 `RecordTime` |
| 云端刷新逻辑及统一更新接口 | `app/src/main/java/com/example/iot3/data/MonitorViewModel.java` | `refreshFromCloud()`、`updateReading()` 等 |
| 图表线条、坐标、填充效果 | `app/src/main/java/com/example/iot3/ui/TrendChartView.java` | `onDraw()`；编辑器样例在 `isInEditMode()` 分支 |

### 例子：修改首页标题

在 `strings.xml` 找到：

```xml
<string name="home_title">环境概览</string>
```

把内容改成你需要的标题即可，布局里通过 `@string/home_title` 引用它。

### 例子：修改卡片圆角

在 `themes.xml` 的 `Panel` 样式中修改：

```xml
<item name="cardCornerRadius">24dp</item>
```

### 真实数值现在从哪里来

运行时数值来自 `NleCloudApi.getSensors()`，经 `NleSensorMapper` 按 `ApiTag` 解析后传给 `MonitorViewModel.updateReading()`。改字段映射看 `NleSensorMapper.java`；修改请求实现看 `NleCloudApi.java`；账号、密码、设备编号在本地 `cloud.properties` 配置，由 BuildConfig 传入运行代码。

`strings.xml` 的 `temperature_value` 等仅供布局初始预览。运行时未取到数据前显示占位符，成功后由统一模型覆盖；修改 XML 数字不会改变云端数值。`EnvironmentData.demo()` 仍保留为开发参考，但实际 APP 不调用它。

趋势图构造函数中 `isInEditMode()` 的样例只供 Android Studio 预览，实际图表只使用收到的真实采样。设计时属性说明参见 [Android 官方文档](https://developer.android.com/studio/views/tool-attributes-views)。
